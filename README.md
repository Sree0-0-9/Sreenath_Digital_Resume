# Sreenath Suman Digital Resume

An original, responsive digital resume for Sreenath Suman, positioned across Finance, Data and Business Analysis.

## Features

- Editorial finance focused visual design
- Responsive hero and career impact summary
- Professional experience timeline
- Interactive draggable skill sphere
- Filterable GitHub project portfolio
- Education, credentials, recognition and work eligibility
- Direct contact links and an inline FormSubmit message sender
- Accessible navigation and reduced motion support

## Local Preview

Open `index.html` directly, or run a static local server from this folder.

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## GitHub Pages

Create a repository such as `Sreenath_Digital_Resume`, copy these files to the repository root, and enable GitHub Pages from the `main` branch.

The expected site address will be:

`https://Sree0-0-9.github.io/Sreenath_Digital_Resume/`

## Contact Form

The form posts asynchronously to FormSubmit and keeps visitors on the website. FormSubmit sends a one-time activation email to `sreenathsuman1@gmail.com` when the endpoint receives its first live submission. Approve that message before publishing so later enquiries are delivered normally.
